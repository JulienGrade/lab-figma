# Lab Figma · Manuel de référence

Un manuel interactif en français, organisé en 29 fiches consultables par chapitre ou via la recherche.

## Ouvrir le lab

Double-clique sur `index.html` pour l’ouvrir dans ton navigateur. Le sommaire, les fiches et la recherche fonctionnent directement depuis le fichier. Comfortaa est chargée depuis Google Fonts si le navigateur a accès à Internet. Hors ligne, le navigateur utilise sa police de secours.

## Modifier le projet

- `index.html` définit la structure de la page.
- `styles.css` contient la charte et les styles responsives.
- `docs.js` contient les chapitres, les fiches et leurs liens de référence.
- `app.js` gère le rendu, les liens directs et la recherche.

## Publier le dépôt sur GitHub

Crée un dépôt vide sur GitHub, puis exécute ces commandes depuis le dossier extrait. Remplace `lab-figma` dans l’URL si tu as choisi un autre nom de dépôt.

```bash
git remote add origin https://github.com/JulienGrade/lab-figma.git
git push -u origin main
```
